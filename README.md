# Desafio Técnico Gauss

Projeto para o desafio técnico da Gauss.

## Observações

verificar se você tem instalado em sua maquina o Git e o Node.js

## Instalação

Clone o repositório - https://github.com/euazuos/gauss-desafio.git  - para a sua própria máquina

## Verificações

Verifique se todas as dependêcias (Devido ao Node.js) estão instaladas.

## Execução

em seguida, execute o projeto na sua maquina.
